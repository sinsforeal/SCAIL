# tools\neutral_replay.py  (447 lines)

DOCSTRING:
Re-run a day that already happened through two prompt trees and compare.

The question is whether prompts written as mechanism plus a reference to the
character sheet (`prompts_neutral/`) make the same girl behave the same way as
prompts with her friends' names written into them (`prompts/`).

The method is a held-input A/B rather than two simulations. Two simulated days
diverge on their first coin flip and after that nothing they differ on can be
attributed to the prompt. So the inputs are the real ones: every model call the
live bot made on 2026-09-01 is in `logs/<run>/llm_calls.jsonl` with its whole
message list and its answer. For a chosen role this script takes those recorded
calls, keeps the user message byte for byte, swaps only the system prompt, and
runs both sides several times.

Several times is the point. A model at temperature 1.0 does not repeat itself,
so a single pair proves nothing: the run-to-run spread inside one prompt tree
has to be measured before a difference between the two trees can be called a
difference at all. Every comparison below is a field's agreement across
repetitions of the same prompt, set against its agreement across the two.

Nothing here touches the live save, the live prompts or the running bot. The
save is copied first and read only for the relationship meters; the neutral
system prompt is assembled in memory by `tools/neutral.py`.

    python tools/neutral_replay.py --estimate                  # what it would cost
    python tools/neutral_replay.py --go --reps 3
    python tools/neutral_replay.py --go --roles state,director --reps 3
