DOCSTRING:
A fixed vocabulary of stamps, so the same feeling is the same stamp.

The record narrated them -- 「（悲しそうなキツネのスタンプ）」, 「スタンプで返しとく」 --
which is fine, because there is no image and a stamp read as text is what
everybody actually sees. What was NOT fine is that every one was invented
fresh, so a girl's stamps were never twice the same and none of them was
hers. LINE stamps come in sets: a person buys a set and uses it for months,
and which set you use is a thing about you.

So the stamps are a closed list. Each person owns a set (`data/cast.json`
`stamps`, or the default here), the beat and turn prompts are given only
their own, and a stamp is written 「[スタンプ: <name>]」 -- the same shape as
the photo marker, so the same readers carry it. A name off the list is
snapped to the nearest one on it, or dropped.
