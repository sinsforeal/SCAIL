# Easier to work in, to audit and to expand: the measures

<!-- doc: reference -->

The owner's ask, after the third character's baseline closed:
make the codebase easier to work in, easier to audit and easier to expand,
and start implementing. What was done in that pass, what each measure protects,
and what is left, ranked. The earlier cleanup review
(`docs/review-2026-09-03-cleanup.md`) is the earlier pass; its phases 0 to 3
are done and its open items are his decisions, listed at its §5. This is the
pass after it, and its rule is different: **a fault found tonight became a
check that would have found it, before it was fixed.**

## 1. What was done

**A check for unfilled prompt tokens** (`tools/fills_check.py`, in smoke,
stops a restart). Every role of every character in `characters.json`
rendered through the config's own fill, the way the running bot renders it;
a placeholder that survives fails, with the roles it reaches. A token inside
a fork her existence drops is not a hole; a role whose section is switched
off for her is skipped and named. Twelve of the fourteen tokens added when the
shared prompts were made person-neutral had no value in the third character's packages, and twenty-one
had none in the second character's file; the check says which of those
reach a running character (none) in a tenth of a second, where establishing
that had taken a reading. Any config can be checked with `--config`.

**The existence matrix** (`tools/existence_matrix.py`, in smoke, stops).
Every combination of the four answers a sheet can give (a body or not, a
world or not, how she sees him in three ways, an account or not), twenty-
four kinds, each built on a scratch config and a fresh save with the model
and the network refused, her system prompt and what she carries rendered
the way the first reply would. Two kinds had ever been booted. The first
run found three faults and one cost, all fixed at the source in the same pass:

- **A character in a world with no account could not render her prompt**:
  the media diet asked the account monitor for her liked accounts and the
  monitor made a directory from the blanked data path. A blank path is now
  the empty case in the monitor's one path function
  (`sensors/x_monitor.py:_paths`), so every reader of the account store
  inherits it.
- **A resident in a world had no sight words**: the sight table is keyed on
  how she sees him and the world program registered only the phone-app
  words. The program now registers the resident's words when her sheet says
  she is resident (`tomoe/app.py:build`), since her sheet's two answers are
  independent by design.
- **The world program spent a model call inside its constructor**: the
  cast-arcs planner ran at build when it was due, which on a fresh save is
  always. Moved to the loop's first pass (`tomoe/app.py:every_pass`), same
  gate, tried once per date; a build of her never spends now, and the
  matrix went from eight minutes to three seconds.
- The harness gained `refuse_network()` and `refuse_model_before_build()`
  (`tools/harness.py`) so any scratch build can be made unable to spend or
  to fetch, before the App exists.

**The checks index** (`tools/checks_index.py` writes `docs/checks.md`,
regenerated by smoke). Every check smoke runs, in order, with the tool it
runs and whether a failure stops a restart, read off smoke's own source; and
every hand-run test tool with the first line of its docstring. A new check
is a row the moment it is written; a deleted tool fails the docs check.

**The module map** (`tools/modmap.py` writes `docs/modmap.md`, regenerated
by smoke). Every module in the live tree: its kind (runtime, shared mind
library, the machine's, a program's), its docstring, the wires it declares,
the config sections and model roles it reads, its kv keys counted, its spec
if it has one, and the tools that name it. The page a reader wanted before
opening a file.

## 2. What is left, ranked by what it would save

1. **A role knows its section.** The fills check maps a role to the section
   that can switch it off by name, and says so in its skip line. The config
   should carry it: one `section` field per role in `models`, checked at
   boot the way `ROLE_STANCE` is, so that "does this role run for her" is a
   lookup and not a guess. Half a day; it also lets `/help` and the module
   map say which roles a character runs.
2. **One harness for the hand-run tests.** `tools/harness.py` exists and
   eleven tools still carry their own copy of its eight lines (the review's
   §3.2, last row). Moving them costs an hour each and makes the network and
   model refusals available to all of them.
3. **The scratch config carries the machine's key.** The matrix copies
   `config.json` to the temp directory, key and all, the way the smoke save
   copy does; a build that never calls the model does not need it. A
   `Config` that accepts a blank key when every call is refused would let
   the scratch copy carry none.
4. **The loop as a table.** The cleanup plan's phase 3 item 2 put the
   command handler in a table (`App.COMMANDS`); the loop's forty stages are
   still a sequence of guarded calls in `App.run`. A table of stages with one
   guard would let the module map and `/help` say what runs when, and let a
   program's hooks be listed rather than grepped.
5. **The docs pass the cleanup review left**: CLAUDE.md to about 110 lines and
   HANDOVER to about 90, his call, because both change what he reads on
   every call.
6. **A smoke check that a program's hook set is complete**: the runtime
   calls the program by name (`_program_call`) and a missing hook is a
   silent default. A list of the hook names the loop calls, checked against
   what each program defines, would name a hook a new program forgot.

## 3. The rule this pass adds

When a fault is found by a person or by a worker, the fix is written second.
First comes the check that would have found it, run to show it fails, and
then the fix, run to show it passes. The three faults above were found by a
worker reading the third character's packages; the matrix now finds them in
three seconds, for every kind of character nobody has built yet.
